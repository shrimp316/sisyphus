# G123 도달 불가능 상한 독립 검토

검토 결론은 **명시된 조건 아래 승인**이다. `verify_gate_bound.gd`와 `reachability-certificate.md`의 무강화 G123 상한에서 반례나 방향이 뒤집힌 부등식을 발견하지 않았다. 검토는 production `_step_v02`, 생성 계수 치환, 실제 지형 조회, 스태미나 계층, 버티기·Slip·속도 상한과 직접 대조했다. 기존 게임의 무강화 완주 불가능이나 제품 적용 적합성을 승인하는 문서는 아니다.

검토한 production controller SHA-256:

`30a312b144383be64fc6fe35b8ad107ebba9a90672d9dda941f9ef8018279944`

## 승인 범위

750~873m에 일정한 45° dry STONE, 접지1, 저항0.2, 내부 회복0, 내부 강화/외부 상태 변경 없음이라는 조건이 필요하다. 기존 속도 상한1.8m/s와 120Hz 스텝을 유지한다. gate 내부 회복0은 원래 급경사의 저속 입력 해제 회복7/s까지 포함한다. A/B/C 또는 원래 코드의 회복을 유지한 경사에는 이 승인을 옮겨 적용할 수 없다.

상한에 사용한 최대 스태미나100과 속도1.8은 무강화 진입자에게 가능한 자원을 과대평가한다. 실제 진입에 이 값을 확보할 수 있는지와 관계없이 불가능을 보이기에는 유리한 가정이다. gate에서 나갔다 재충전한 뒤 재진입하는 전략도, 성공할 마지막 진입 이후의 구간만 택하면 동일한 상한을 적용할 수 있다.

## 잠재량 부등식 대조

`c = 3 sin(45°)-0.2 > 0`, `H = c*x + max(v,0)²/2`는 실제 중력 퍼텐셜을 정확히 계산한 에너지가 아니라 코드에 대해 만든 보수적인 잠재량이다. 실제 전진 저항은 보통 `g+r`이지만 후퇴 마찰까지 허용하려고 `g-r`를 사용한다.

일반 적분에서 가속도는 `F-c` 이하이다. 정지 마찰의 dead zone에서는 가속도0이고 `F≥c`이므로 이 부등식이 유지된다. 출발 시 요구 배율1.25는 저항을 더 크게 하므로 상한에 유리하다. `v,v'>=0`일 때 semi-implicit 위치 적분을 사용하면:

`ΔH = (c+a)*v'*dt - (a*dt)²/2 <= F*v'*dt`.

전진 속도를1.8로 clamp하면 유효 가속도가 더 작아져 상한을 깨지 않는다. 음수 속도에서 양수로 바뀌는 경우에는 `v' <= (F-c)dt`이고, `c*v'*dt + v'²/2 <= F*v'*dt`가 성립한다. 스텝 후 속도가0 이하라면 위치와 양의 속도 에너지가 증가하지 않는다.

버티기는 음수 속도에서 양수로 넘어가면0으로 clamp하므로 지속적인 전진 에너지를 공급하지 않는다. Slip은 양의 관성을 제거하고 비양의 속도로 바꾸며 해당 스텝의 추진을 차단한다. 저항·Slip·후퇴 시 추진 전달 손실을 상한 계산에서 무시하는 것은 공급 예산을 증가시키는 방향이다.

게이트의 실제 생성 구간에서 쉼터/받침/돌턱 부재는 별도 구조 검사 조건이다. 이 검토는 일반적인 외부 위치 점프, 저장 복원으로 위치 변경, 다른 물리 모드에 적용하지 않는다.

## 가중 스태미나와 이산 보정

스태미나 추진 계수의 적분은 `0.5C + 0.3C*0.85 + 0.2C*0.65 = 0.885C`이다. 계수는 스텝 시작 잔량을 읽으므로 계층을 넘어간 스텝은 연속 적분보다 많이 공급할 수 있다.

추진 스텝의 명목 소비량은 최대 `Q=3*1.7/120`이다. 50%,20%,0 경계를 넘을 때의 계수 차이는 각각0.15,0.20,0.65이고 합은1이다. 각 경계를 넘는 추진 구간에서 left-sample 과대평가가 최대 `차이*Q`이므로, 마지막 잔량 초과 소비를 포함한 총 보정은 `Q` 이하이다.

Slip 손실·버티기 소비처럼 추진하지 않는 스태미나 감소는 사용 가능한 적분 구간을 줄인다. 그런 감소가 계층을 건너뛰어도 추진 공급을 새로 만들지 않는다. 따라서 추진 시 가중 명목 소비량의 전체 상한 `0.885C+Q`는 유지된다. 이 논리는 내부 스태미나 회복이나 최대치 증가가 없을 때에만 유효하다.

속도 구간 상한0.45,1.2,1.5,1.8과 힘주기 여부를 모두 비교하는 계산도 대조했다. 실제 다음 속도 대신 `min(1.8,구간상한+F0*dt)`를 사용하고, 후퇴 전달 감소 및 중력을 생략하므로 모두 낙관적인 공급 상한이다. 무강화 최댓값 `R=2.57364950980392`와 최종 공급 예산229.497361721814를 재확인했다. gate 진입 프레임의 최대0.015m 초과 이동을 허용한 필요량236.293582452683보다 **6.796220730869 부족**하다.

## 독립 계산 및 실행

`verify_proof_review.gd`는 실제 생성 컨트롤러에서 5,760개 한 스텝 경계 fixture를 실행했다. 속도·스태미나 계층 직전/정확한 경계/직후, Slip 게이지 직전, Slip 차단 중, 8가지 입력 조합을 포함한다. `ΔH-R*ρ*명목추진소비 <= 1e-8` 검사에서 실패0, 최대 초과0이었다. 이것은 유한 표본 검증이며 연속 상태 전체의 증명으로 제시하지 않는다.

`verify_proof_review.py`는 소비량을 정확한 유리수 `17/6000`의 정수배로 두고, 밀기·힘주기의 모든 이산 소비 조합을 완화한 DP를 별도로 계산했다. 물리적으로 모든 조합이 가능하다고 허용한 push-only 자원 검산이며, 전 물리 입력 탐색이 아니다. 비추진 손실까지 포함한 일반 결론은 위 대수적 유도에 의존한다.

재현 명령:

이 명령은 실제 컨트롤러 경계 검사를 다시 실행하고, DP와 소스/생성 아티팩트 해시를 `tests/balance/results/act1-adjustment-v02/proof-review.json`에 기록한다. 세부 실행은 `proof-review-step.json`과 로그에 남긴다. IEEE 연산 전체에 대한 형식 증명은 수행하지 않았다.

## 승인하지 않은 주장

- 8/8/8의 두 입력 휴리스틱 실패로 모든8/8 조합이 불가능하다고 결론지을 수 없다. 양의 상한 여유는 가능성 증명도 아니다.
- 9/9/9,10/8/0,8/10/0 진입 fixture 통과는 전체0m 출발, 해당 XP 확보, 정상까지의 완주, 인간 조작 가능성의 증거가 아니다.
- 회복 강화는 내부 회복0 gate에서 직접 효과가 없다. 이 gate 하나로 세 계열 모두8~9가 필요하다고 주장하면 안 된다.
- 최대 스태미나를 소진한 급경사에서 긴 안전 후퇴가 항상 가능하다는 증거는 없다. 후퇴·회복·재도전 동선은 별도로 확인해야 한다.
- 이 결과만으로 최초 정상120~180분 목표 또는 적용 가능한 최종 설계를 확정하지 않는다.

원시 metadata의 상위 하네스 설명에는 `without copied integration` 문구가 남아 있다. v0.2에서는 **instrumentation 블록의 source/generated hash와 치환 위치가 우선**한다. 해당 함수는 계수를 바꾼 소스 파생본이다. 분석 manifest도 이 우선순위를 명시한다.
