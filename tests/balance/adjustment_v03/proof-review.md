# v0.3 회복 관문 상한의 독립 검토

검토 대상은 별도 작성자의 `recovery-bound-certificate.md`, `verify_recovery_bound.gd`, 생성 controller의 원본·삽입 코드와 실제 결과 `recovery-bound-search.json`이다. 이 검토자는 해당 증명이나 물리 코드를 작성하지 않았다. 판정은 **명시 조건의 소스 방정식 증명에 대한 조건부 승인**이다. 일반 정책 성공, 전체 경로 통과, 안전한 퇴각을 승인하는 문서가 아니다.

## 핵심 유도 검토

전진 저항을 포함한 `c=3sin45°+0.2`를 사용한다. `v>0.001`에서 시작 보정은 저항을 더 크게 하고, 속도 상한은 에너지를 추가하지 않는다. `v_next<=0`인 스텝은 위치·양의 운동에너지를 늘리지 않는다. Slip의 음수 충격도 양의 운동량을 만들지 않는다. 음수 속도에서 버티기가 가속하더라도 production은 양수가 되기 전에0으로 제한한다.

`v<=0.001` 영역에는 같은 저항 부호식을 그대로 적용할 수 없다는 작성자의 분리가 필요하고 타당하다. 밀기 없는 경우 양의 속도는 생기지 않는다. 밀기 있는 경우 `v_next<=0.001+F0*dt`는 중력·마찰의 순감속과 후퇴 추진 감소를 생략한 상한이다. 무강화 저속 경계비율0.075515 미만은 주 전진 상한2.5736495098보다 작다. 이 처리를 빠뜨리고 전진 마찰식을 모든 속도에 적용하는 유도는 승인하지 않는다.

스태미나 회복 때문에 단조 감소 경계 보정만으로는 충분하지 않다. 이동한 잠재 자원 `E(S)=∫₀ˢ rho(u+q)du`는 `d<=q`인 실제 소비에 대해 `E(S)-E(S-d)>=rho(S)d`를 만족한다. 회복 때 `E` 증가량은 실제 회복량 이하이므로50%·20% 경계를 반복 통과해도 비용을 과소평가하지 않는다. `q=.0425`, 용량100 이상에서는 `E(C)=.885C+.35q`다.

명목 소비가 잔여량을 초과하는 스텝의 보정은 최대`.65q`다. 회복 허용 최소 스태미나1에서0은 관문 내부의 흡수 상태이므로 이 초과 소비는 마지막 진입 이후 최대 한 번이다. 따라서 `.885C+B+q`가 전역 추진 자원 상한이다. 버티기·Slip의 손실은 자원을 줄이며 이 상한을 깨지 않는다. 외부 쉼터를 이용한 재진입은 마지막 진입 시 용량 전체·최대 속도·회복 예산 전체를 다시 허용하는 더 유리한 경계로 덮는다.

## 독립 계산과 검사의 범위

`verify_proof_review.py`는 Python 표준 라이브러리의 정확한 유리수로 소비·회복 경계648개와 반복 회복 스케줄120개를 검사한다. 각 스케줄은2,000개의 선택 뒤 고갈까지 추가로 밀며 계층 재통과·일반 소비·명목 초과 소비·비추진 손실을 포함한다. 이는 유도식을 보조하는 검사이며 전체 IEEE 실행이나 모든 입력의 유한 열거가 아니다.

독립 산술은 무강화의 비율 `1050049/408000`, 자원 `67417/400`, 공급435.3893225061274, 필요441.0160454711788을 재현한다. 부족량은5.6267229650514다. 작성자의 실제 생성 controller5,376조건 검사 결과도 유도와 일치하지만, 해당 유한 검사를 전체 증명의 대용으로 사용하지 않는다.

추가255m·실제 회복 상한140 조건에서도 같은 식을 독립 재계산했다. 무강화 공급589.808293094363, 필요591.901867802555, 부족2.093574708193이 재현된다. 이는 동일한 노면·소비·최소 스태미나1·내부 장애물 없음 조건 아래의 산술 확장 승인이다. 새 배치의 실제 지형 검증·전체 경로·성장별 통과 실행을 이 계산으로 대신하지 않는다. 자료는 `recovery-bound-long-search.json`과 비교하고 해시를 별도로 보존한다.

39~45°로 각도를 바꾼 추가 검토에서는 production 소비식을 다시 읽어39°의 소비1.66,40° 이상의 소비1.7을 확인했다. `c=3sinθ+.2`, `q=3d/120`, 모든 전진 구간과 힘주기의 비율·저속 분기를 함께 재계산했다. 같은 자원 유도는 이 양의 q와 해당 각도의 감속 조건에서도 유효하다. 39°/114m/B0의 부족3.010507500413,39°/127m/B10의 부족3.797351144931,40°/125m/B10의 부족10.779571370163을 독립 재현한다. 총 회복량이 같다면 회복률7과40의 상한은 같지만, 실제 입력 정책의 회복 활용과 성공률은 같다고 가정하지 않는다. 해당 비교와 해시는 `angle-bound-verification.json`을 참조한다.

```powershell
python tests/balance/adjustment_v03/verify_proof_review.py
```

검토에 사용한 소스·작성자 증명·원시 결과 해시는 v0.3 결과의 `proof-review.json`에 기록한다. 이후 코드나 조건이 바뀌면 이 검토는 자동으로 새 조건에 적용되지 않는다.

## 승인 범위 밖

- 기준은190m,45° dry STONE, 내부 쉼터·받침·돌턱·구매 없음,120Hz, 원래 성장·소비, 유한 실제 회복량 무강화80 이하, 회복 최소 스태미나1이다. 다른 길이·회복 시간·배율·노면은 재계산해야 한다.
- `recovery_min_stamina=0`에서는 ‘고갈 뒤 재회복 불가’ 가정이 없어지므로 이 자원 상한을 그대로 승인하지 않는다. 그것이 곧 해당 조건에서 성공 가능하다는 주장도 아니다.
- 회복 기회 시간은 환경의 새 테스트 조건이다. 현재 게임이 원래 이 제한을 가지고 있다고 해석할 수 없다.
- 회복량과 스태미나가 남았다는 사실은 안전한 중간 퇴각의 증거가 아니다. 완전 고갈 뒤 내부 회복·장거리 퇴각은 보장되지 않는다.
- 성장한 진입 fixture의 성공은 전체 경로 성공과 별도다. 정책·시간제한 실패는 불가능의 증거가 아니다. 인간120~180분이나 미래140개 노드의 밸런스도 이 검토로 입증되지 않는다.
