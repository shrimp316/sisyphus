# SISYPHUS 1막 난이도 조정 실험 v0.2

2026-10-27. **실험 전용 결과이며 실제 게임은 변경하지 않았다.** 후속 지시인 ‘무강화 완주 불가능’을 이전 v0.2 문서의 완주 허용 조건보다 우선했다. 숙련의 석판·EXP 직접 소비·세피로트·프레스티지는 구현하지 않았다.

**결론:** 기존 지형에서 회복·경사 연결·Slip 계수만 조정한 D1~D3은 무강화 완주를 막지 못했다. 별도 G123 관문은 명시한 물리 조건에서 무강화의 임의 입력 통과가 불가능함을 상한식으로 검증했다. 실제 강화 조합 여러 개의 전체 등반과 실제 XP 재도전도 확인했다. 그러나 일반·숙련 자동 정책의 최대 강화 실패, 회복 투자 열세, 균형 성장의 180분 미완주가 남았다. **모든 목표를 만족하는 적용 확정안은 없다.**

## A. 현재 문제의 재확인

새 기준 실험에서 일반 무강화는 **10/10 완주, 평균 617.11초**, 각 8회 강화는 **10/10, 611.63초**였다. 이전 3시드의 약617.8초 결과와 일관된다. 숙련 무강화의 이전 3/3 결과는 [이전 보고서](../../../../docs/act1-balance-report.ko.md)의 선행 증거이며 새 10시드 숙련 실험으로 부풀리지 않는다.

무강화 일반의 평균 스태미나는 88.10/100, 정지·입력 해제 휴식은 1.64초였고 Slip·고갈은 없었다. 42m 오르막마다 8m 쉼터가 반복되고, 평지에서는 움직이며 입력을 놓아도 초당10 회복한다. 추진력은 이미 전진 상한1.8m/s에 자주 도달하므로 강화가 완주 가능성을 바꾸기보다 시간을 조금 줄이는 구조다.

또한 현재 오르막의 거의 정지 상태에는 초당7 회복이 있다. 따라서 긴 경사에서 몇 정책이 실패했다는 사실만으로는, 정교한 정지·회복·재출발을 포함한 모든 입력을 배제할 수 없다. 이 점 때문에 G123의 자원 상한 실험을 별도로 추가했다.

## E. 성장 관문, 정체와 재도전 검사

### G123: 무강화 차단을 입증한 실험 조건

- 750~873m를 연속123m·45°·dry STONE·접지1·저항0.2로 설정한다. 청크15/16/17의 오르막 길이는50/50/23m이고 해당 세 청크의 젖은 구간은 비에서도 비운다.
- 750m 이후 **비쉼터의 입력 해제 회복×0**이다. 거의 정지 상태의 회복도 차단한다. 현재 설정은 관문 뒤 남은 비쉼터에도 적용되므로 ‘관문 내부만 바꿨다’고 표현하지 않는다. 모든 실제 쉼터 회복은 유지한다.
- 관문 내부에는 쉼터·받침·돌턱·구매가 없다. 742~750m 직전 쉼터와 873~900m 다음 쉼터가 있다. 원래 앞쪽 지형과 총1,000m는 유지한다. 내부에 있던 턱을 옮겼으며 요구 추진력1.6은 올리지 않았다.
- 성장 rank 자체를 검사하는 잠금, 강제 Slip·Runaway·추락은 없다.

**상한 검증:** `c=3sin45°−0.2`, `H=c*x+max(v,0)²/2`를 사용하면 이산 한 스텝에서 `ΔH≤추진력×max(새속도,0)×dt`다. 버티기는 전진 에너지를 만들지 않으며 Slip은 이를 감소시킨다. 모든 밀기/힘주기 속도 구간과 스태미나 추진계층, 이산 스텝 경계 초과 소비를 포함하고 진입 속도1.8과 최대 스태미나를 모두 허용해도:

- 무강화 공급 예산 상한 **229.49736**
- 필요한 진행량의 하한 **236.29358**
- 부족량 **6.79622**

따라서 이 조건의 무강화 통과는 임의 입력·후퇴·재진입을 허용해도 불가능하다. 이 결론은 자동 실패율과 독립적이다. [전체 유도](../../adjustment_v02/reachability-certificate.md), [계산·실행](gate-bound-123.json), [독립 검토](../../adjustment_v02/proof-review.md)를 제공한다. 소스 방정식 수준의 조건부 증명이며 IEEE 프로그램 전체의 정리 증명기 검증은 아니다. 기존 게임·ABC·D 또는 변경된 길이/회복 계수에 이 결론을 옮길 수 없다.

성장 후에는 9/9/9, 10/8/0, 8/10/0의 관문 통과뿐 아니라 **0m 출발→1,000m 완주**를 실제 입력으로 확인했다. 단순히 상한이 넉넉하다는 이유로 가능하다고 판단한 것이 아니다. 10/8/0과8/10/0은 실제 XP 캠페인에서도 관문 진입·통과를 재현했다.

### EXP 확보와 강화, 실패 후 복구

0~250m의 원래 지형을 유지했고 G 예비87회 모두 이를 통과했다. 직전 쉼터에서 정상적인 정지·완전 회복·강화 구매가 관측됐다. 균형 캠페인 첫 회차는 쉼터 약744.86m에서 누적420 XP로 다섯 번째 포인트를 구매했고, `2/2/1`로 관문에 진입했다. 첫 추락 후480 XP와 rank를 보존한 채 새 산에서 시작해, 두 번째 회차 약144.17m에서 누적520 XP로 추가 강화했다.

**첫 접근에서 충분한 포인트가 주어지는 구조는 아니다.** 직전 쉼터까지 첫700m 보상420 XP는5포인트이며, 확인된 혼합 통과 빌드는18포인트를 사용했다. 최소 필요 포인트는 입증하지 않았다. 반복 도전의 사전 구간에서는 동일700m를 다시 지나며280 XP를 얻을 수 있고, 현재 XP 상한6150은 모든30포인트 비용과 같다. 관문 너머 전용 보상에 의존하지 않고 성장할 경제 경로가 존재한다. 실제 성공 캠페인도 여러 자연 추락과 사전 쉼터 구매를 거쳤다. ‘성장 관문 이전 충분한 기회’를 **첫 회차만으로 충분함**으로 해석하면 이 후보는 그 조건을 충족하지 않는다.

완전 고갈한 관문 안에서는 회복0이고 버티기 추진도 사라지므로 안전한 장거리 후퇴를 보장하지 않는다. 관문 안 임의 지점에서 쉬며 탈출할 수 있다는 주장은 하지 않는다. 확인된 복구 경로는 **직전 쉼터의 회복·구매, 자연 Runaway·추락→성장 보존→새 회차→재구매·재도전**이다. 추락 후 진행이 막힌 영구 상태는 관측하지 않았다. 안전한 중간 퇴각을 필수로 요구한다면 G123은 추가 설계가 필요하다.

## G. 숙련의 석판 도입 시사점 — 설계 제안, 미구현

현재 XP는 직접 소비 재화가 아니라 누적 레벨 기준이다. 50m당 회차 보상20, 새 개인기록 보너스10이다. 250m 구간당 첫 통과150·반복100, 실제 생성기의200m 구역당 첫120·반복80이다. 새 기록 보너스는 반복마다 다시 주지 않고, 한 회차에서 되돌아와 같은 구간을 다시 지나도 중복 지급하지 않는다.

| 균형 성장 | 총 포인트 p | 현재 누적 XP 비용 `5p²+55p` |
|---|---:|---:|
| 각3강 | 9 | 900 |
| 각5강 | 15 | 1950 |
| 각8강 | 24 | 4200 |
| 각9강 | 27 | 5130 |
| 각10강 | 30 | 6150 |

현재 곡선에서 균형8강은 oracle 약160분에 도달하지만, 회복 rank는 회복0 관문에서 직접 기여하지 않는다. 반면 힘·용량에18포인트를 집중한 빌드는 관문을 넘었다. 단순 XP 지급량 증가만으로 이 투자 편향은 해결되지 않는다.

1. **성장 역할을 먼저 분리한다.** 근력은 추진 여유, 호흡은 지속 시간·소비 효율, 자세는 Slip·버티기·회복 가능한 후퇴·적정 속도 운용 등 서로 다른 문제를 해결하는 방향을 검토한다. 이는 미구현 효과 제안이며 이번에 그 노드들을 테스트했다는 뜻이 아니다.
2. **관문을 한 특정 노드의 소유 검사로 만들지 않는다.** 현재처럼 힘×용량의 연속적인 물리 교환 관계를 유지하되, 자세 또는 회복 경로도 대안이 되는 별도 자원 경로를 설계하고 다시 상한·성공 입력을 검증한다.
3. **8~9노드의 ‘일반적인 목표’와 최소 통과 비용을 분리한다.** 균형27포인트와 효율 배분18포인트의 차이를 방치한 채 전체 EXP 비용만 올리면 회복·균형 투자가 더 불리해진다. 인간 입력 주기별로 여러 배분의 성공 가능 영역을 먼저 맞춘 후 가격을 조정한다.
4. **EXP 직접 소비를 도입하면 누적 기록과 지갑을 분리한다.** 현재 level-point 지급과 새 지갑 소비를 중복 적용할지 명확히 정하고, 최대 누적XP6150에 묶인 현 규칙을 그대로 지갑 규칙으로 복사하지 않는다. 이번에는 어느 쪽도 구현하지 않았다.
5. **120~180분 조정은 이후 측정으로 결정한다.** 관측된 균형180분의4750~4770 XP와 각9강 비용5130의 차이, 약160분의 각8강 도달은 경제 조정의 출발점이다. 반복 보상·비용곡선을 조정하면 성장 속도는 변하겠지만, 이 비율을 그대로 인간 완주 시간 예측이나 확정 할인율로 사용하지 않는다. 강화 후 입력 실패 병목도 함께 해결해야 한다.

## 검증·재현·남은 한계

기존 게임 회귀336개, 기존 하네스43개, 새 계측21개로 Godot **400개 검사 통과**. 기존 Python 집계13개와 새 집계12개도 통과했다. 30/144FPS의 동일 입력 결과, 120Hz, Slip·Runaway·돌턱·현재 성장·XP 중복 방지·추락 보존·정상·저장 호환성을 검사했다. 생성 중립 물리는 세대1~6·맑음/비와 대조했지만 본 조정 실험의 지원 범위는 생성 세대6이다.

관문 구조는100시드×맑음/비에서 검사했다. 소스 상한식을 보조하는 입력 경계 검사1,120개, 별도 검토자의 실제 컨트롤러5,760경계 검사, 가중 스태미나 자원 DP4조건을 제공한다. 이 유한 검사는 수학적 유도와 역할이 다르다. 고정 전체 경로4회와 실제 성장72회의 원시 입력 재생이 모두 일치했고, 다른 검토자가 실제 성장8회를 다시 재생했다. 정체 검출기 smoke도1건 재생 일치를 확인했다. 회귀 실행 명령·결과와 원본 로그는 [verification.json](verification.json)에 보존했다.

원시 JSONL·설정·시드·자연 날씨·소스 해시·정책 버전·생성 물리 코드·입력 gzip을 보존했다. 구간 노출은200m와250m 두 관점이며 서로 더하면 이중 계산이다. 직접 물리 호출로 비용을 줄인 gate oracle 자료에는 세부 계측이 없는 필드를0으로 채우지 않고 결측으로 남겼다. 자세한 재현 명령은 [도구 README](../../adjustment_v02/README.md), [gate route README](../../adjustment_v02/gate_route_README.md)에 있다.

필수 결과: [metrics.csv](metrics.csv), [bands.csv](bands.csv), [stamina.csv](stamina.csv), [slip.csv](slip.csv), [stalls.csv](stalls.csv), [campaigns.csv](campaigns.csv), [manifest.json](manifest.json). 추가 노면·경사·날씨별 노출은 [terrain.csv](terrain.csv), 실제 지형 배치는 [geometry.csv](geometry.csv)다. 모든 시간·분위값·성공 조건부 완주 시간은 해당 파일에 분리했다.

표본은 자동 정책 실험이다. 인간 플레이, 미래 석판 효과, 안전한 관문 내 장거리 퇴각, 모든 저·중성장 입력의 불가능은 검증하지 않았다. 이 한계를 포함해 보고서를 해석해야 한다.
