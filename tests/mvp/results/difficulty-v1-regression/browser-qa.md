# 난이도 조정 브라우저 확인

2026-10-27, Godot 4.5.1 debug Web / 로컬 Chromium. `MVP Web` 프리셋을 `tests/mvp/build_web.py --qa`로 내보냈다. 공개 사이트에는 배포하지 않았다.

기존 사용자 플레이 탭의 `127.0.0.1:8766` 저장에 접근하지 않고, 별도 origin `127.0.0.1:8767`에서 새 검증용 진행을 만들었다.

## 직접 관찰

- 새 게임과 일반 D 입력으로 이동했다. 15초 일반 밀기 후 26m 화면에서 스태미나 감소와 진흙 효과 안내가 보였다. 이 관찰은 정확한 소모율 측정이나 인간 난이도 평가를 대신하지 않는다.
- 키를 놓은 첫 시도는 최고 14m 후 추락했고 결과 화면에서 정상 재도전했다. 두 번째 시도는 46m 쉼터에 도달했다.
- Esc 일시정지 후 저장하여 메뉴의 최고 기록 46m 및 이어하기 활성화를 확인했다.
- 마지막 위험 안내 문구 수정 후 다시 내보내고 실제 reload했다. 저장의 46m 기록이 남아 있었고, 이어하기 후 잔여 관성 이동을 거쳐 48m 쉼터에서 휴식·체력 회복을 확인했다. [최종 빌드 이어하기 화면](browser-final-continue.png), [빌드 파일 SHA](web-build.json).
- 지형별 안내가 실제 지형에 따라 바뀌고 EXP·숙련 HUD와 함께 표시된다.
- [쉼터 도착 화면](browser-difficulty.png)은 실제 입력 중 캡처다. 일반 밀기만으로 실제 Slip이 발동한다는 정량 근거는 별도 37개 단위 검사의 35° 고정 경사 실험이다. 이 화면으로 Slip 발동을 입증하지 않는다.

## 관측한 제한

- 실제 1920×1080 전체 화면에서는 정상 비율로 표시됐다. 946×884 일반 브라우저 창에서는 검은 여백과 세로 압축이 관측됐다. 이번 변경에 웹 셸 수정은 포함하지 않았으며 이 표시 문제는 해결된 것으로 보고하지 않는다.
- 브라우저 콘솔에 `Invalid polygon data, triangulation failed` 및 기존 `scripts/main.gd`의 `_draw_terrain` 호출 스택이 관측됐다. 이후 등반·쉼터·저장은 진행됐다. 오류 없는 브라우저 검증으로 집계하지 않으며, 지형 그림의 다각형 문제는 별도 미해결 사항이다.
- 이 브라우저 확인은 짧은 입력·화면·저장 확인이다. 1,000m 인간 완주나 최초 정상 120~180분을 검증하지 않았다.
