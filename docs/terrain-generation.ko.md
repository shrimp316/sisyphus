# 쉼터와 경사 생성 변경 — 2026-10-12

새 등반부터 쉼터를 기존 18~32m에서 **8m**로 줄인다. 한 구간은 오르막 42m와 쉼터 8m로 이루어지며, 20구간·전체 1,000m 길이를 유지한다.

각 오르막의 경사는 기존 구간별 기준값 주변 ±4° 범위에서 따로 추첨한다. 전체 범위는 4~32°다. 오랫동안 낮은 접지력을 견뎌야 하는 젖은 바위 구간은 16~20°로 제한한다. 구간 종류, 지면, 난이도 연속 제한, 날씨 추첨은 기존과 같다. 쉼터에 있던 단차는 줄어든 쉼터 안의 같은 상대 위치로 옮기고, 국소적으로 젖는 구간은 기존 위치를 유지한다.

지형 생성 버전을 4로 올리고 별도의 시드 난수 생성기를 사용한다. 같은 등반 시드는 같은 지형을 만들고 새로운 시드는 다른 경사를 만든다. 저장할 때는 완성된 구간 정보를 보관하므로 이어하기에서 경사를 다시 추첨하지 않는다. 버전 1~3으로 시작한 진행 중 등반과 디버그 코스는 기존 길이와 경사를 유지한다. 새 구성을 보려면 새 등반을 시작한다.

Godot의 난수 알고리즘은 엔진 버전 사이의 호환성을 보장하지 않는다. 저장된 실제 지형을 복원하는 방식으로 이 영향을 피한다. [Godot 4.5 RandomNumberGenerator 문서](https://docs.godotengine.org/en/4.5/classes/class_randomnumbergenerator.html)
