너는 Godot 4 기반 2D 게임 프로젝트의 에셋 구현 담당이다.

프로젝트명: SISYPHUS / 시지프스
장르: 2D 사이드뷰 등반 로그라이트
현재 상태: ver.0.2 시스템 구현 완료, 테스트 직전 단계
목표: 첨부된 레퍼런스 시트를 바탕으로 “게임에 바로 넣을 수 있는 실제 에셋 세트”를 제작/정리하고, Godot에서 바로 연결 가능한 형태로 구성하라.

중요:
- 첨부된 이미지는 “컨셉/레퍼런스 시트”이며 최종 게임용 원본 에셋이 아니다.
- 한 장짜리 시트를 그대로 쓰지 말고, 실제 사용 가능한 개별 PNG / sprite sheet / metadata 형태로 분리된 에셋을 만들어라.
- 모든 최종 에셋은 배경이 투명해야 한다.
- 모든 캐릭터 프레임은 동일 캔버스 크기와 동일 기준점(발 위치, 중심축)을 유지해야 한다.
- 가능한 한 현재 프로젝트 구조를 존중하되, 없다면 아래 제안 구조를 기준으로 생성하라.

참고 레퍼런스 파일:
1. 시시포스_2d_게임_스프라이트_시트.png
2. 시지푸스_2d_산악_환경_에셋_시트.png
3. 시지푸스_2d_게임_에셋_시트.png

1. 게임 아트 방향
====================================

아트 스타일:
- 반실사풍 2D 페인터리 스타일
- 횡스크롤 사이드뷰
- 신화적 / 고독한 / 거칠고 무거운 분위기
- 과장된 만화풍보다는 묵직한 질감
- 전체적으로 바위, 먼지, 바람, 피로, 긴장감이 느껴져야 함
- 색감은 자연스러운 흙/돌/회색/갈색/안개색 계열 중심
- UI 아이콘은 돌에 새긴 듯한 느낌 또는 바위 질감 느낌
- 모든 실사용 에셋에는 설명 텍스트를 넣지 말 것
- 에셋 안에 제목, 숫자, 캡션 같은 문구를 삽입하지 말 것

카메라/뷰 기준:
- 전부 “좌→우 진행” 기준의 측면 사이드뷰
- 캐릭터는 기본적으로 오른쪽을 향하는 프레임으로 제작
- 필요시 좌우 반전으로 사용 가능해야 함

4. 캐릭터 에셋 상세 명세
====================================

캐릭터명: Sisyphus

비주얼 특징:
- 근육질 성인 남성
- 긴 머리 또는 중간 길이의 거친 머리
- 짧은 수염 또는 거친 얼굴
- 누더기 천/허리천 정도의 간단한 의상
- 맨발 또는 매우 단순한 발 표현
- 전체적으로 바위와 싸우는 듯한 육체적 긴장감

중요:
- 캐릭터 프레임은 “게임 애니메이션용”으로 제작한다.
- 각 프레임은 같은 크기의 캔버스에 놓여야 한다.
- 발바닥 기준선이 최대한 일정해야 한다.
- 캐릭터의 크기 비율이 프레임마다 튀지 않게 한다.
- 모든 모션은 오른쪽 방향(side view) 기준으로 제작한다.
- 배경 투명 PNG로 저장한다.

기본 캔버스 권장:
- 512x512 PNG 투명 배경
- 필요 시 384x384 또는 프로젝트 기존 규격에 맞춰도 되지만 전 애니메이션 통일 필수

필수 애니메이션:
1) idle
- 6프레임
- 가볍게 숨쉬고 체중이 실리는 미세한 움직임
- 완전 정지처럼 보이지 않게 할 것

2) push
- 8프레임
- 일반 밀기
- 몸이 앞으로 기울고 발이 지면을 미는 느낌
- 손은 “앞의 돌을 미는 위치”와 자연스럽게 맞는 동작
- 전 프레임에서 손의 높이/접점이 크게 튀지 않게 할 것

3) heavy_push
- 6프레임
- 강하게 밀기 / burst
- 힘이 더 많이 들어가는 모션
- 다리와 등 근육 긴장감 강조
- 흙/먼지가 살짝 일어나는 연출 가능하나 캐릭터 본체와 분리 가능한 경우 분리하는 것을 우선

4) brace
- 6프레임
- 뒤로 미끄러지는 돌을 버티는 모션
- 상체는 뒤로 젖고, 다리는 버티며, 팔은 앞으로 밀어내는 느낌
- “밀기”와 실루엣 차이가 분명해야 함

5) exhausted
- 6프레임
- 지친 상태 / 휴식 / 숨 고르기
- 허리를 숙이거나 무릎을 짚거나 잠시 주저앉는 흐름
- 너무 쓰러진 상태 말고 “게임 중 잠깐 회복 가능한 상태” 느낌

출력 형식:
- 개별 프레임 PNG
- 각 애니메이션별 spritesheet PNG 1개
- Godot SpriteFrames 리소스(.tres 또는 .res) 가능하면 함께 생성
- metadata json 생성

파일명 예시:
assets/character/sisyphus/idle/idle_01.png
assets/character/sisyphus/idle/idle_02.png
...
assets/character/sisyphus/push/push_01.png
...
assets/character/sisyphus/spriteframes/sisyphus_idle_sheet.png
assets/metadata/sisyphus_animations.json

metadata 예시 내용:
- animation_name
- frame_count
- fps
- frame_size
- pivot_x
- pivot_y
- baseline_y
- loop 여부

권장 fps:
- idle: 6 fps
- push: 8 fps
- heavy_push: 8 fps
- brace: 8 fps
- exhausted: 6 fps

5. 돌(Boulder) 에셋 상세 명세
====================================

돌은 플레이어가 미는 핵심 오브젝트다.
크고 무겁고 질감이 살아 있어야 한다.

필수 종류:
1) default_boulder
2) rough_boulder
3) wet_boulder
4) snow_boulder

조건:
- 배경 투명 PNG
- 동일한 기준 크기 유지
- 프로젝트 내 collision과 맞추기 쉽게 원형에 가까운 실루엣
- 지나치게 삐죽한 실루엣은 피할 것
- 캐릭터 손 위치와 맞춰 쓰기 쉽게 측면에서 일관성 유지

권장 출력:
- 개별 PNG
- 필요하다면 8방향 회전처럼 보이는 “rolling frame” 세트 추가 가능
- 단, 테스트 우선이므로 최소한 static sprite는 반드시 제공

권장 크기:
- 256x256 또는 384x384 투명 PNG
- 프로젝트 기존 스케일이 있다면 그에 맞춤

파일명 예시:
assets/boulder/boulder_default.png
assets/boulder/boulder_rough.png
assets/boulder/boulder_wet.png
assets/boulder/boulder_snow.png

선택 사항:
- rolling_01 ~ rolling_08 프레임 생성 가능 시 생성

6. 지형 / 바닥 / 경사 에셋 상세 명세

ver.0.2에서 테스트할 핵심 지형을 우선 구현한다.
지형은 타일맵보다 “모듈 조각” 느낌이어도 좋다.
중요한 것은 반복 사용 가능성과 시각적 식별성이다.

필수 기본 지형:
1) rock_ground
2) gravel_ground
3) mud_ground
4) wet_rock
5) snow_ground

필수 특수 지형:
6) steep_slope_up
7) convex_slope_up
8) concave_slope_down
9) ledge
10) foothold_rest_platform
11) small_stone_step

조건:
- 배경 투명 PNG
- 좌우 연결 시 큰 이질감이 없도록
- 상단 보행면이 명확하게 보이게
- Godot에서 배치하기 쉽게 기준 방향 통일
- 가능하면 바닥 두께/하부 암반도 같이 표현하여 월드 배치가 쉬워지게
- 지나치게 복잡한 원근감 금지. 사이드뷰 일관성 유지

권장 크기:
- 512x256 또는 기존 프로젝트 규격
- slope 계열은 동일 높이계열로 맞추기
- rest platform은 돌이 잠깐 걸릴 수 있는 “안정적인 홈” 느낌 강조

파일명 예시:
