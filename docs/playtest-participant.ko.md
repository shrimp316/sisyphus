# 《시지프스》 플레이 테스트 안내

받은 ZIP 파일을 **모두 압축 해제**한 뒤, 폴더 안의 **Playtest.cmd**를 더블클릭하세요. Godot 설치는 필요 없습니다. 게임 파일과 함께 받은 폴더를 그대로 유지해 주세요.

Windows 10/11의 64비트 PC용 테스트 빌드입니다. 모든 PC 환경에서 동작을 확인한 것은 아닙니다. 서명되지 않은 실행 파일이므로 실행이 차단되거나 오류가 나면 표시된 내용을 진행자에게 알려 주세요.

## 시작하기

1. 진행자에게 받은 참가자 번호 **01~10**을 입력합니다. 다른 사람의 번호를 사용하지 마세요.
2. 먼저 **연습 코스(practice)**에서 조작을 익힙니다.
3. 연습을 마치면 게임을 종료하고, 다시 **Playtest.cmd**를 실행하여 같은 번호로 **일반 코스(normal)**를 선택합니다.
4. 처음 시작할 때는 새 세션(new), 중단한 등반을 계속할 때는 이어하기(resume)를 선택합니다. 이어할 세션은 진행자의 안내를 따르세요.

플레이 시간은 진행자의 안내에 따르세요. 잘하는 모습을 보여줄 필요는 없습니다. 편한 방식으로 시도하고, 헷갈리거나 예상과 달랐던 순간을 기억해 주세요.

## 조작

| 키 | 기능 |
|---|---|
| D 또는 → | 돌 밀기 |
| 밀기 + Shift | 강하게 밀기 |
| Space | 버티기 |
| Esc | 일시정지 메뉴 |
| Enter | 화면에 표시된 시작·계속·재시도 |
| M | 소리 켜기·끄기 |

소리를 들을 수 있는 환경을 권장합니다. 종료할 때는 Esc 메뉴의 **저장 후 종료**를 사용하세요. 게임 창을 닫아도 저장합니다. 저장 실패 안내가 나오면 창을 그대로 두고 진행자에게 알려 주세요.

## 플레이를 마친 뒤

일반 코스 게임을 종료하면 기록 질문이 표시됩니다. 질문은 먼저 플레이한 뒤 읽어 주세요. 연습 종료 후에는 기술적 문제나 자유 의견만 남깁니다. 혼자 진행한 답변은 본인의 경험에 대한 자기보고로 기록됩니다. 좋았던 점과 불편했던 점 모두 도움이 됩니다.

- 직접 겪거나 관찰한 내용은 짧은 상황 설명이나 발언을 함께 남깁니다.
- 판단할 수 없거나 해당 상황을 경험하지 못했다면 **unknown(판단 보류)**를 선택합니다. 답을 만들 필요는 없습니다.
- 가능하면 다른 참가자의 추락 장면도 한 번 보세요. 보지 못했다면 해당 관전 항목은 판단 보류로 남깁니다.

마지막으로 **playtest-results 폴더 전체를 ZIP으로 압축해서 진행자에게 직접 보내 주세요.** 이 폴더에는 이번 테스트의 답변 JSON, 게임 저장 파일과 실행 로그가 들어 있습니다. 폴더 밖의 파일은 보낼 필요가 없습니다. 프로그램이 결과를 자동으로 전송하지 않습니다.

이름·연락처 등 개인정보는 답변에 적지 않아도 됩니다. 참가자 번호만으로 기록을 구분합니다.
