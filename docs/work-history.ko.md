# SISYPHUS 작업 경과

이 문서는 2026-10-07까지 이 대화에서 진행한 작업의 요약이다. 메시지 기록은 `conversation-messages.json`, 첨부 원본은 `references/`를 참고한다.

1. **초기 기획과 Godot 구현** — 사용자가 v0.1 게임 시스템 명세를 제공하고 Godot 프로젝트 구현을 요청했다. 돌 밀기, 힘주기, 버티기, 스태미나, 미끄러짐, 추락, 정상 도달, 한글 UI, 소리, 저장/재개를 구현했다.
2. **환경과 v0.2** — 후속 단계 및 상세 명세를 반영해 산 조합·날씨·표면 재질과 관성·부분 추락·돌턱 중심의 핵심 조작 MVP를 정리했다. 기억·성장·이벤트·철학 엔딩 전체는 구현한 것으로 간주하지 않으며, 범위는 `v02-alignment.ko.md`에 기록했다.
3. **참가자 테스트 준비** — 사용자가 Windows 실행 파일 전달 방식을 선택했다. 참가자 번호별 저장 분리, 연습/본 코스 분리, 사후 응답 및 결과 집계 도구, Windows 패키지를 준비했다. 실제 참가자 결과는 아직 없다.
4. **GitHub와 브라우저 배포** — 사용자가 GitHub 업로드와 웹 플레이를 요청·승인했다. `shrimp316/sisyphus` 공개 저장소와 GitHub Pages를 만들고, Web 내보내기·자동 배포·브라우저 저장 및 한글 폰트를 연결했다. 초기 게시 커밋은 `27bc98e`, 검증 문서 커밋은 `cae4558`이다.
5. **실사용 아트 제작** — 사용자가 레퍼런스 이미지 4개와 같은 내용의 에셋 명세 4개를 제공했다. 참고 시트를 그대로 사용하지 않고 built-in image_gen으로 새 이미지를 제작했다. 캐릭터 32프레임, 돌 4종, 지형 11종, 소품 7종, FX 36프레임, UI/마커 11종, 시트 11장 등 PNG 112장을 제공했다.
6. **아트 연결과 검증** — 13개 SpriteFrames와 프리뷰 4개를 추가했다. 기존 물리·저장 동작을 유지하며 실제 게임 렌더링을 교체했고, 독립 검토로 지형·마커 피벗을 수정했다. 아트 커밋 `bb292a7`을 웹에 배포했다. 파일·리소스·GPU·브라우저 검증은 `assets-verification.ko.md`에 정리했다.
7. **전체 백업 요청** — 사용자가 제외된 자료까지 모두 GitHub에 올려 달라고 요청했다. 최신 아트가 들어간 Windows 실행본을 재생성하고, 전체 작업 파일·도구·캐시·로그·캡처·원본 첨부와 생성 이미지까지 Releases 백업에 포함했다. `.git`은 저장소 자체가 대신하며 백업 산출물의 재귀 포함은 제외한다.

아트는 테스트용 일관된 팩이다. 최종 수작업 리터칭, 급경사 손/발 IK, 눈·이벤트의 실제 게임 시스템, 모바일 터치, 인간 참가자의 재미 검증은 후속 범위다. 생성 프롬프트와 재현 도구는 저장소에 포함한다.
