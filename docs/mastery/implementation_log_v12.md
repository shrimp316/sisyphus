# 숙련의 석판 v1.2 — 독립 프리뷰 구현 결과

## 범위와 재현

기준 HEAD는 `8385f031700dc509068edb468f7361d2ca397968`이고 작업 브랜치는 `feat/mastery-tablet-ui-v12`다. 기존 타이포그래피를 재사용했다. 기존 메인 씬·물리·경제·저장·배포 preset을 교체하지 않고 새 씬·스크립트·데이터·테스트·문서만 추가했다. 최종 변경 명세는 [파일 목록](changed_files_v12.md), 실제 통합 경계는 [통합 계획](integration_plan_v12.md)에 정리한다.

Godot 4.5.1에서 `godot/scenes/mastery/mastery_preview.tscn`을 실행하면 된다. 예:

```powershell
& .tools/godot/Godot_v4.5.1-stable_win64_console.exe --path . res://godot/scenes/mastery/mastery_preview.tscn
python -X utf8 tests/mastery/build_web_preview.py
python -m http.server 8772 --bind 127.0.0.1 --directory builds/mastery-v12
```

웹은 `http://127.0.0.1:8772/index.html`로 열며, 산출물은 독립 debug export다. 정식 배포를 변경하거나 업로드하지 않았다. 명세의 승인 경계에 따라 이번 추가물은 커밋·푸시하지 않았다.

- ZIP SHA-256: `776877f77cae96efa88a13442d1e09f8a7a39fd60a7ee187e6036f3b96ac5c13`.
- 런타임 PNG 131개 = 원화 65개 + 그리스어 글리프/표면 66개, 총 10,448,555 bytes.
- 131개가 모두 기존 미추적 `assets/ui/mastery/`에 이미 있었고 ZIP과 바이트 단위로 일치했다. 복사·재압축·재생성·이름 변경·덮어쓰기를 하지 않았다.
- 기존 inventory의 65개 해시·해상도·크기와 ZIP 원본을 대조했다. 신규 66개는 inscriptions 경로를 별도 조사했다.

- ARTBOARD의 `composed`와 `missing_as_illustrated`는 실제 독립 PNG로 오인하지 않았다.

표시 조립 과정에서 원화 레이어를 선택했다. 배경 자체에 외곽 장식이 포함되어 있어 `slate_outer_frame_overlay.png`를 별도 최상단에 중복 합성하지 않았다. 이 PNG는 **중앙이 투명**하다. 최종 픽셀 검사에서 투명 1,720,446 / 불투명 353,154 / 중간 알파 0픽셀로 확인했으며, 초기 화면 표시만 보고 전부 불투명이라고 설명했던 판단을 정정한다. `special_panel.png`에는 CSV 중심과 어긋나는 Ω/프레임이 구워져 있어 중복 프레임을 만들므로 공통 빈 석재 패널과 5개 개별 원본 플레이스홀더로 조립했다. 두 파일 모두 원본을 보존했다. 잠금용 `special_seal.png` 원화 안의 Ω는 그대로지만, 특별 노드의 데이터상 그리스어는 미배정이며 legacy extensionText를 사용하지 않는다.

## 35노드와 진행 상태

`MasteryNode` 하나, `MasteryTrack` 하나, `MasteryGate` 하나를 재사용한다. 일반 노드 중심은 원본 CSV를 읽어 배치하며 10+10+10개, 특별 노드는 5개다. 노드 이미지 조합에 따른 완성형 PNG를 새로 만들지 않는다.

| 계열 | 그리스어 10글자 | 현재 게임 대응 |
|---|---|---|
| 근력 | ΒΙΑΚΑΙΩΣΙΣ | strength, 최대 10랭크 |
| 지구력 | ΜΕΓΑΛΗΡΩΜΗ | endurance, 최대 10랭크 |
| 호흡 | ΤΑΧΕΙΑΠΝΟΗ | recovery, 최대 10랭크 |
| 특별 5개 | 미배정 | 효과·비용 미정, 구매 거부 |

일반 노드별 engraved/ready/active PNG를 매핑에 따라 선택한다. 잠금에는 봉인을 표시한다. 강화 완료 글리프에는 근력 `#F6AF4D`, 지구력 `#38A7FF`, 호흡 `#37E7E4`의 런타임 색상을 적용한다. 파일 픽셀은 변경하지 않는다. 상태 판정은 구매 완료 → 도달 자격 → 선행 강화 → 미사용 강화점 순서이며 선택 테두리는 독립이다.

| 모의 상태 | 근력 자격 | 지구력 자격 | 호흡 자격 | 특별 자격 | 총 자격 |
|---|---:|---:|---:|---:|---:|
| 0m | 0 | 0 | 0 | 0 | 0 |
| 250m | 4 | 3 | 3 | 0 | 10 |
| 500m | 7 | 7 | 6 | 0 | 20 |
| 750m | 10 | 10 | 10 | 0 | 30 |
| 1,000m 첫 정상 회차 | 10 | 10 | 10 | 0 | 30 |
| 첫 정상 이후 다음 회차 | 10 | 10 | 10 | 5 | 35 |

자격은 구매 완료가 아니다. 첫 회차의 fixture EXP는 기존 거리 지급 모델의 0/150/300/450/600이고 다음 회차는 600을 유지한다. 이는 해당 자격 노드 전체를 즉시 살 수 있다는 뜻이 아니다. `30점 시연`은 기존 최대 레벨 XP 6150을 주입하는 **개발용 mock** 버튼이며 실제 플레이 보상·경제 제안이 아니다. 구매에는 별도 메모리 Progression을 사용하고 누적 EXP를 차감하지 않는다. 구매 초기화는 mock 랭크만 초기화하며 최초 도달·정상 자격을 유지한다. 실제 프레스티지 또는 저장 기능으로 구현하지 않았다.

## UI와 애니메이션

세 행과 특별 구역, 제목/EXP/강화점/회차, 동적 상세 패널을 구성했다. 클릭·Tab·Enter·Esc, 잠금 노드의 정보 조회, 중복 구매 방지, 구매 실패 시 효과 미실행, 정상 완료의 다음 회차 분리를 제공한다. 개발용 상태 선택과 30점·초기화·연출 건너뛰기는 프리뷰 컨트롤러에만 있다.

해금 상태를 먼저 확정한 뒤 직사각형 석문과 제공된 시지프스 push 01~05 포즈를 재생한다. 스프라이트시트까지 동시에 로드하지 않는다. 연출은 행의 석문 영역만 잠시 가리며 건너뛰기/닫기 이후 데이터와 입력이 복원된다. 행 10개 완료 시 순차 공명은 시각 효과로만 재생한다. 원본 캐릭터의 프레임 포즈를 사용하며 새 관절 모션으로 주장하지 않는다.

2~4막 화살표는 미구현 안내와 함께 비활성화했다. 비문 은행은 12개 coreText와 전체 글리프 존재를 검증했고, 140개 예약 슬롯/한 화면 35개 구조의 스키마를 준비했다. 미정인 후속 막의 효과·비용·게이트를 만들어 넣지 않았다.

## 검증과 남은 항목

실행 명령, 최종 수치, Web 크기와 증거는 [테스트 결과](tests_v12.md)를 따른다. 빌드 성공만으로 Web UI PASS로 보고하지 않았다. 초기 Web 실행에서 CSV의 자동 translation import 때문에 노드 데이터가 누락되는 오류를 발견했고, 새 CSV sidecar의 `importer="keep"` 설정과 독립 빌드 데이터 whitelist로 수정했다. 최초 실패 로그도 보존했다.

기존 세이브 v4/Progression v1 호환성은 임시 fixture로 검사했으며 실제 사용자 세이브를 읽거나 쓰지 않았다. Linux/Firefox 실기, Godot Profiler의 GPU/프로세스 메모리, Web 초기 로딩 시간·FPS 및 실제 후속 막 페이지 전환 시간은 측정하지 않은 경우 PASS로 표기하지 않는다. 라이브 구매·저장 해금 이력·프레스티지·정식 메뉴 연결은 [별도 승인 목록](integration_plan_v12.md)에 남긴다.
