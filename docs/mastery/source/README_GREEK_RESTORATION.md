## 추가된 것
- 그리스어 21종 고유 문자 × 3개 표현(engraved, ready, active)의 128×128 투명 글리프 PNG 63개.
- track별 공통 돌 표면 `rune_stone_face_{strength,endurance,breath}.png` 3개.
- `mastery_greek_node_mapping_v11.csv` — 35개 노드 중 일반 30개에 비문 매핑, 특별 5개는 아직 문자 배정 안 함.
- `mastery_greek_inscription_bank_v11.json` — 4개 막 × 3개 분야의 기존 10글자 + 구 5글자 비문을 모두 보존.
- `preview_GREEK_restored_on_original.png` — 원래 750m 시연 화면에 원문자를 덧씌운 **합성 검토본**. 이 미리보기 자체는 런타임 에셋이 아닙니다.
- `ARTBOARD_TO_ACTUAL_ASSETS.csv` — 사용자가 보여준 참고 에셋 시트의 표기명과 실제 납품 경로가 다른 항목의 대응표.

## 1막 35 노드의 그리스어 원문
- 근력 1~10: ΒΙΑΚΑΙΩΣΙΣ
- 지구력 1~10: ΜΕΓΑΛΗΡΩΜΗ
- 호흡 1~10: ΤΑΧΕΙΑΠΝΟΗ
- 특별 숙련 1~5: 효과가 미확정이라 그리스어 **미배정**.

## Godot 4 렌더링
1. 기존 공통 노드 이미지와 상태 오버레이를 사용합니다.
2. 각 일반 노드의 기존 계열 아이콘 대신 `rune_stone_face_<track>.png`를 중앙에 한 번만 올립니다. (노드 범주 아이콘은 행 왼쪽에 계속 사용)
3. 각 노드의 `greek_codepoint`에 따라 글리프 텍스처(파일명은 16진 유니코드 값)를 덮습니다.
4. 잠금 중에는 기존 자물쇠 오버레이를 최상단에 표시합니다. 구매 가능 시 ready, 구매 완료 시 active를 사용합니다.
5. active 글리프는 PNG가 흰색 발광 계열이므로 Godot의 `modulate`로 근력 #F6AF4D / 지구력 #38A7FF / 호흡 #37E7E4를 곱합니다.
6. 비문 배열은 성능을 위해 각 행에서 순서에 맞게 공유하고, 특수 5개에는 비문을 자동 배정하지 않습니다.

## 중요
- **사용자가 보여준 에셋 시트는 컨셉 아트보드이지 실제 PNG 전체 파일들의 정확한 미리보기가 아닙니다.** 일부 작품은 한 장에만 존재했고, 일부는 조합식으로 만들어서 개별 그림과 완전히 동일하지 않습니다.
- 이번 작업은 그리스어 문자 복원과 기존 분리 에셋 보존이 목적이며, 빠져 있는 원본 레이어를 새롭게 복원했다는 뜻이 아닙니다.
- 그리스어 문구는 과거 대화에 작성된 게임용 비문 초안이며 역사적 고증 완료 문구가 아닙니다.
- 개별 에셋 확대 품질은 이전 v1.0과 같으며 이번 버전으로 원본 예술 품질이 달라지지 않습니다.
