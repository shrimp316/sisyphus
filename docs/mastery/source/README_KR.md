# SISYPHUS — 숙련의 석판 개별 PNG 에셋 패키지 v1.0

## 목적
첨부된 세피로트 UI 패키지처럼 그래픽을 독립 PNG 단위로 분리한 **원화 중심 에셋 패키지**입니다. 게임 코드/씬은 포함하거나 수정하지 않습니다. `assets/ui/mastery/` 아래 PNG를 Godot 4 프로젝트에 복사한 뒤 화면을 조립합니다.

## 구성 원칙
- 아트 방향: 기존 SISYPHUS의 풍화된 석재, 그리스 신전, 청동, 금빛 각인.
- 화면 디자인 기준 1920×1080, 16:9.
- 일반 노드 30개(근력 10/지구력 10/호흡 10)와 별도 특별 노드 5개는 **논리적인 노드 슬롯**으로 생성합니다.
- 그림은 공통 베이스 + 테두리 + 계열 아이콘 + 잠금/구매/선택 오버레이로 합성합니다. 완성형 PNG 35×상태 수만큼 복제하지 않습니다.
- 세 종류 일반 아이콘은 각 계열을 대표하는 시각 요소이며, **노드별 고유 능력 아이콘이 확정된 것은 아닙니다.**
- 5종 특별 아이콘은 모두 **플레이스홀더**입니다. 구체적인 효과가 결정되면 교체해야 합니다.
- 위치/잠금 조건의 근거는 `mastery_node_layout_v1.csv`; 모든 실제 PNG 경로는 `mastery_asset_inventory_v1.csv`.
- 2~4막은 각 막당 동일한 35개 슬롯을 배치하면 총 140개까지 확장할 수 있습니다. 현재 다른 막 고유 아트는 포함하지 않습니다.

## 1막 거리 조건
- 최초 250m: 근력1~4, 지구력1~3, 호흡1~3 = 10개 구매 자격 개방
- 최초 500m: 근력5~7, 지구력4~7, 호흡4~6 = 20개 누적
- 최초 750m: 근력8~10, 지구력8~10, 호흡7~10 = 30개 누적
- 최초 1000m: 특별 5개 해금 조건 성립, **다음 회차부터 구매**
- 개방과 구매는 별개입니다. 프레스티지에 의한 구매 초기화·도달 이력 보존은 **게임 코드가 처리**해야 합니다. 이 ZIP 자체는 해당 기능을 구현하지 않습니다.

## Godot 4 조립 권장 순서
1. 배경 `background/slate_bg_main.png`를 화면 전체 1920×1080에 표시합니다.
2. `panels/track_panel_common.png` 3개와 `panels/special_panel.png` 1개를 배치합니다. **원본의 과거 막별 석판 표식은 별도 패널과 라벨로 가립니다.**
3. `nodes/node_base.png`, `nodes/node_ring_bronze.png`, `icons/icon_*.png`를 반복 인스턴스로 합성합니다.
4. 조건 미충족 시 `nodes/state_story_locked.png` + `nodes/state_padlock_symbol.png`, 조건 충족 시 `nodes/state_available.png`, 구매 시 `nodes/state_purchased.png`, 선택 시 `nodes/state_selected.png`를 최상단에 중첩합니다.
5. 각 노드 이름·강화 수치·EXP 비용·문자/번호는 **Godot Label에서 렌더링**합니다. 원화 이미지의 텍스트는 고정 데이터로 사용하지 않습니다.
6. `character/`와 `gates/`는 막 해금 이벤트에만 인스턴스화해 메모리를 절약할 수 있습니다.
7. `effects/`는 발광과 파티클 소스로 사용합니다. 화려한 효과는 필요한 순간에만 로드합니다.
8. `navigation/` 화살표와 상세 패널은 재사용합니다.

## 실제 에셋 경고
- 일부 장식·아이콘·이펙트는 단일 컨셉 아트보드에서 추출하고 배경을 알파 처리한 분리본입니다. **완전한 원본 PSD 레이어나 일러스트레이터 벡터 원화는 아닙니다.** 확대·이동·합성은 가능하지만 최대 원화 해상도의 한계가 있습니다.
- `slate_bg_main.png`은 기존의 4행 석판 원화를 보존한 파생 배경이며, 이전 막 명판 일부는 아직 베이스에 포함됩니다. 완성된 페이지에서는 별도 트랙/라벨 패널이 이를 가립니다. 완전한 빈 배경을 재원화한 것으로 오인하지 마세요.
- 5프레임 시지프스 포즈는 프로토타입 애니메이션용. 연속 관절 애니메이션이나 60fps 모션캡처가 아닙니다.
- `preview_*.png`와 `asset_contact_sheet.jpg`는 검수 이미지이며 런타임에 넣지 마세요.
- 이번 패키지는 그래픽 납품입니다. Godot에서 실행·성능 검증을 마쳤다고 주장하지 않습니다.

## 파일 구성
- `background/` 풀 스크린 배경, 상단 원화, 투명 외곽 장식
- `panels/` 공통 트랙, 특별 트랙, 좌측 레이블, 상세 패널
- `nodes/` 공통 원형 프레임, 노드 상태, 잠금 기호, 연결선
- `icons/` 근력/지구력/호흡 카테고리 대표 문양
- `special/` 5개 플레이스홀더 아이콘과 특별 봉인 프레임
- `gates/` 실제 직사각형 돌벽 및 반쪽 게이트
- `character/` 시지프스 독립 PNG와 6프레임 시트
- `effects/` 금빛·청록·파랑 발광 및 이펙트
- `navigation/` 좌우 화살표, 빈 구매 버튼, 헤더 명판

## 보존 원칙
기존 PNG·Godot 씬·게임코드 파일을 **수정하거나 덮어쓰지 않았습니다**. 모든 파일은 새로운 경로 아래 생성된 파생 결과물입니다.
