# MVP 저장과 이전 규칙

MVP는 `user://sisyphus-mvp-v1.json`을 사용한다. 기존 `sisyphus-v1.json`은 자동으로 읽어 덮어쓰거나 레벨·강화를 변환하지 않는다. Web mirror 키는 `sisyphus:mastery-mvp:v1:<URL 디렉터리>:user://sisyphus-mvp-v1.json`이다. 정식 Web 키와 구별한다.

최상위 `version=5`, `save_version=1`, 증가하는 `revision`과 저장 시각, `world`, `run`, `mastery`, 회차·추락 수, `prestige_phase`, `phase_elapsed`, 미완료 첫 해금 안내, 사운드·화면 설정을 저장한다. `mastery`의 내부 버전은 2이며 지갑·현재 프레스티지 주기 누적·역사상 누적 EXP, 구매·영구 자격, 최고 기록, 말쿠트·실·프레스티지 수, 보상 처리한 회차 토큰, 구간 보상 기록을 구분한다.

`run.mastery_run`은 STR10 발동/쿨다운, BRE07 전진 경계·남은 회복, BRE10 사용 여부, SPC02 충전과 사용 쉼터, SPC04 후퇴 사건, SPC05 준비와 남은 거리 등 실제 회차 상태를 저장한다. 프로필의 능력 요약은 이 실제 상태와 일치해야 한다. `MasterySave`는 파일을 적용하기 전에 월드·프로필·물리·진행 단계의 교차 일관성을 검사한다.

- 일반 추락 후 재시도: 지갑·구매·자격 보존, 새 회차 토큰 및 일회성 능력 초기화.
- 정상 프레스티지: 지갑·현재 주기 EXP·구매 초기화, 역사 기록·자격·실 보존. 말쿠트는 정확히 ×5이며 반복 곱셈하지 않는다.
- 새 게임: 확인 창 이후 현재 MVP 파일을 타임스탬프 백업하고 새 프로필 생성. 백업 실패 시 원본을 유지하며 초기화를 중단한다.
- 이전 게임: 빈 MVP 프로필의 조작법 화면에서 명시적으로 가져온다. 원본 백업 성공 후 최고 거리와 750m까지 일반 구매 자격만 이전한다. 기존 EXP·레벨·강화·프레스티지는 변환하지 않는다. 1,000m 기록도 첫 정상 이벤트 완료로 간주하지 않는다.

파일 저장은 임시 파일 기록·flush·rename 순서다. Web은 별도 localStorage mirror도 사용하며 복원 시 유효한 후보 중 revision이 큰 상태를 고른다. 복원 실패 파일은 그대로 두고 이유를 표시한다. 저장 실패 중에는 게임 진행과 구매를 막고 재시도를 제공한다.

프레스티지 처리 토큰과 진행 단계는 같은 payload에 기록된다. `PRESTIGE_COMMIT`에서 반영 전/후 저장 모두 복원할 수 있고, 이미 처리한 토큰의 보상은 다시 지급하지 않는다. 모든 7개 단계와 두 회차를 실제 씬 및 디스크 재읽기로 검사한다. 브라우저 증거와 OS 전원 손실 같은 미검증 범위는 [검증 기록](verification.md)에 별도로 남긴다.
