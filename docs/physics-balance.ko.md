# 경사·후퇴·미끄러짐 조정

2026-10-26. 새 등반의 경사와 현재 물리의 후퇴·SLIP 페널티를 강화했다.

## 새 산의 경사

생성 세대 6은 원본 경사의 기준값을 5도 높이고 ±4도 범위에서 무작위 배치한다. 마른 지형의 상한은 36도, 하한은 8도다. 젖은 바위는 접지력을 고려해 맑음 22도·비 20도 상한을 사용하고, 비로 젖는 일반 돌 구간은 22도로 제한한다. 따라서 모든 구간이 정확히 5도씩 높아지는 것은 아니다.

오르막 42m와 쉼터 8m, 50m마다 회복·레벨업 평지, 100m마다 받침을 두는 배치는 유지한다. 진행 중인 저장의 지형은 다시 생성하지 않으며, 높아진 경사는 **새 등반부터** 적용한다. 생성 세대 1~6 저장을 읽을 수 있다.

## 아래로 굴러가는 돌

중력은 기존처럼 `3 × sin(경사)`이고 속도는 120Hz 고정 간격으로 누적한다. 후퇴 중 밀기의 전달력은 정지에서 100%, 후퇴 속도 2m/s 이상에서 35%가 되도록 연속으로 줄어든다. 속도를 키 입력으로 바로 뒤집지는 않는다. 빠르게 내려오는 돌은 Space로 제동한 뒤 밀어 올리는 것이 유리하다.

Space의 제동력과 스태미나 소모 규칙은 유지한다. 소진 상태에서는 무료 밀기·제동이 생기지 않는다. 후퇴 속도가 -4m/s에 도달하면 기존처럼 폭주 판정이 받침보다 우선한다.

## SLIP 페널티

미끄러짐 발생 순간 전진 관성을 잃고, 아래쪽으로 0.65m/s 충격과 스태미나 8 손실을 한 번 받는다. 충격으로 더해지는 후퇴는 -3.5m/s까지만 적용하며, 이미 그보다 빠르게 후퇴하는 돌을 감속시키지는 않는다. 이후의 중력 때문에 폭주에 도달할 수는 있다.

발동한 고정 프레임부터 밀기·힘주기가 차단되며, 기존 0.7초 동안 Space 버티기로 대응한다. 버티기는 충격 이후의 이동을 제동하며 이미 지불한 스태미나 손실을 환불하지 않는다. 진행 중인 SLIP을 저장·재개할 때 충격과 비용을 다시 부과하지 않는다. 후퇴·SLIP 조정은 생성 세대 3~5의 기존 저장에도 적용한다. 생성 세대 1·2의 레거시 물리는 바꾸지 않는다.

수치는 초기 밸런스 조정값이다. 자동 검증과 별도로 실제 플레이에서 반응 시간, 후퇴 손실 거리, 쉼터 도달 난도를 확인해야 한다.
