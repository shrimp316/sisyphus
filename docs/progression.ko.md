# 경험치와 성장

등반을 반복해도 경험치와 선택한 능력은 남는다. 저장 파일 버전은 4이며 기존 버전 1~3의 산, 진행 위치, 최고 기록은 유지한다.

- 진행 거리 50m마다 해당 회차 첫 통과에 20 XP를 받는다. 개인 최고 기록의 새 50m 구간은 추가 10 XP를 준다.
- 추락 뒤 같은 회차에서 다시 오르면 중복 지급하지 않는다. 결과 화면에서 새 등반을 시작하면 회차 보상만 다시 받을 수 있다.
- 첫 레벨업은 60 XP이며 다음 레벨마다 요구량이 10 XP씩 증가한다. 누적 6,150 XP에서 최대 레벨 31이다.
- 레벨마다 선택권 하나를 얻는다. 쉼터에서 돌이 멈추면 선택 화면이 열리고 물리 시뮬레이션이 멈춘다. 여러 선택권은 순서대로 사용한다.
- 받침이 없는 일반 쉼터에서도 선택할 수 있다. 새 등반의 자동 정지 받침은 49.75m부터 100m 간격으로 총 10개이며, 회복·레벨업 평지는 기존처럼 50m마다 유지한다.
- `1` 밀기 힘, `2` 최대 스태미나, `3` 회복 속도 또는 화면 버튼으로 고른다. 각 선택은 기본 수치의 2%를 더하며 능력별 최대 10회, 총 20%까지 성장한다.
- 최대 스태미나는 100에서 최대 120까지 증가한다. 강화 순간에 체력을 채워 주지는 않으며 쉬어서 회복한다. 새 등반은 강화된 최대 스태미나로 시작한다.
- 경험치 획득, 능력 선택, 새 등반 때 즉시 저장한다. 브라우저에서는 기존 파일 저장과 로컬 저장소 백업을 그대로 사용한다.
- 예전 저장을 처음 불러올 때는 레벨 1로 시작한다. 이미 지나간 거리와 최고 기록은 보상 기준점으로만 옮기며 경험치를 소급 지급하지 않는다.

## 검증

`tests/progression_verification.gd`는 경계 거리, 여러 구간 동시 통과, 중복 보상 방지, 새 회차 보상, 성장 상한, 잘못된 저장의 원본 보존, 실제 힘·회복 변화, 쉼터 선택과 물리 정지, 입력 처리, 높은 스태미나 재저장, 기존 저장 이전을 검사한다. 테스트 저장은 매번 `.tools/progression-*` 아래로 격리된다. `--capture`를 GPU 실행에 추가하면 HUD와 선택 화면을 같은 폴더에 저장한다.
